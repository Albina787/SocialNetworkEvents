# SocialNetworkEvents

Мини-проект для практической работы №4 по теме "Реализация доменных событий".

## Сценарий
Пользователь отправляет запрос в друзья, другой пользователь подтверждает запрос.

## События
- FriendRequestSentEvent — отправка запроса в друзья
- FriendRequestAcceptedEvent — подтверждение запроса

## Обработчики
- Push-уведомление о запросе
- Логирование события
